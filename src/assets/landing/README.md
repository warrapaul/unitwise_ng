# Landing page screenshots

The landing page shows the images in this folder. Each one is a sample image marked "SAMPLE".
To use a real screenshot, replace the file with yours under **the same name**. No code change is needed.

| File | What to capture | Size to take it at |
|---|---|---|
| `hero-desktop.png` | Landlord's rent overview with "Payments to confirm" (Rent page), on a computer | Browser window 1440 × 900 |
| `hero-phone.png` | A tenant's bill: amount due, rent/water/garbage, "Pay with M-Pesa" | Phone, 390 wide (any phone is fine) |
| `tenant-phone.png` | The tenant's "My rent" screen, showing an amount owing | Phone, 390 wide |
| `step-1-bill-the-month.png` | The month's bills for a building, ready to send | Crop to a 4:3 area, e.g. 800 × 600 |
| `step-2-collect-by-mpesa.png` | M-Pesa payments received | Crop 4:3 |
| `step-3-confirm-payments.png` | Payments to confirm | Crop 4:3 |
| `step-4-chase-overdue.png` | The overdue list with a few tenants ticked | Crop 4:3 |

Tips:
- Use demo data, not real tenants' names or phone numbers.
- Shapes are fixed: a computer screenshot fills 16:10, a phone shows its top part, a step shows 4:3. Anything taller is cropped from the bottom, so put the important part at the top.
- PNG is fine. Keep each file under about 300 KB, for example by running it through https://squoosh.app, so the page stays fast on mobile data.
- Browsers keep old images for a while: after replacing, hard-refresh (Ctrl+Shift+R) to see the new one.
